## 7.5 المشاريع (Projects)

اتربط:
- قائمة المشاريع بالبحث والـ pagination، وتعديل الاسم، والحذف، وهيدر صفحة المشروع (الاسم، ومين عمله، والتاريخ). من `GET C/projects` و`GET C/projects/{id}` و`POST C/projects/{id}` (`_method=put`) و`DELETE C/projects/{id}`.
- إنشاء مشروع من صفحات المرشحين على `POST C/projects`.
- قائمة «Add to Project» من `GET C/projects-list` (الـ id والاسم، والبحث شغال).
- إضافة مرشحين لمشروع على `POST C/projects/assign-to-users` (`assignee_ids[]` و`projects_ids[]`). شغالة من 3 أماكن: «Add to Project» و«Create project» في صفحة المتقدمين (بـ `userId` مش ID التقديم)، وزرار «Add Candidates» في صفحة المشروع (من `users-list`). قاعدة المواهب وAI Talent Match لسه بيانات تجريبية من غير user id، فالإضافة منهم لسه تجريبية.
